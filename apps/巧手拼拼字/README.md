# 巧手拼拼字

用生活物品代表漢字筆畫，讓學生把物品拖進米字格拼出字。字形與筆順依香港《小學學習字詞表》及《常用字字形表》。
前身是「巧手猜猜畫」（多人猜圖），後來叫過「巧手猜猜字」，因為玩法是拼不是猜，所以改成現在這個名字。

## 玩法

| 模式 | 說明 |
| --- | --- |
| 筆畫圖鑑 | 24 件物品各代表哪一筆，可按基本／複合與年級篩選。遊戲中右上角的「錦囊」用同一個元件，兩邊看到的對照永遠一致。 |
| 練習模式 | 物品自動吸到正確位置與角度，並鎖住筆順：工具欄只亮出「現在該寫的那一筆」。只收筆畫標註已覈核的字。 |
| 挑戰模式 | 沒有吸附、沒有鎖序，自己擺自己轉。按「拼好了」分三項算：種類、筆順、位置。 |
| 老師設定 | 建字簿（一課一本）、加減練習字、匯出匯入 JSON。 |

## 一筆一物，一物一筆

24 件物品：6 個基本筆畫（點＝水滴、橫＝筷子、直＝蠟燭、撇＝羽毛、捺＝滑梯、趯＝紅蘿蔔）
加 18 個複合筆畫。一件物品終身只代表一個筆畫，`assertStrokeTableIntegrity` 在啟動時做雙向唯一檢查，
撞件會直接丟錯，不會等到課堂上才發現。

帶鈎的幾筆靠材質分辨：雨傘是布、屋簷是瓦、長靴是皮、衣帽鈎是金屬、耳機是塑膠、豆芽是植物、湯匙是餐具、球桿是運動器具、水龍頭是金屬水管。

平撇、直撇、平捺沿用母筆畫同一件物品，只改擺放角度。點只用一顆水滴，放進格子時跟著那一筆轉。

## 資料從哪裡來

字形筆順不是猜的，兩支製作期腳本產生：

```bash
npm run gen:charset   # 香港《常用字字形表》4824 字白名單 → src/data/hkCharset.json
npm run gen:chars     # 筆順資料與筆畫標註 → src/data/chars.json
```

`gen:charset` 取 [kitty-panics/cn-tables](https://github.com/kitty-panics/cn-tables) 整理的教育局 2000 年修訂本。
這份表只決定「哪些字是港標收錄字」，老師加字時用它擋掉異體與非港標字；它不含筆順。

`gen:chars` 抓筆畫路徑，三層優先序：

1. `scripts/overrides/<字>.json` — 人工修正檔
2. animCJK **ZhHant** — 繁體筆順，animCJK 明列香港教育局《小學學習字詞表》為參考來源
3. makemeahanzi — 覆蓋率高但是內地筆順，會標成「筆順待核」

ZhHant 對港標字表的覆蓋率約 20%，但涵蓋的正是最高頻那一批，剛好對上小一至小三；
makemeahanzi 覆蓋 97%。兩者格式相同（`strokes` 路徑 + `medians` 中線），直接餵給 Hanzi Writer 的 `charDataLoader`。
差異是真的存在：`花` 在 ZhHant 是 8 筆、makemeahanzi 是 7 筆，正是港台與內地草字頭寫法之別，所以 ZhHant 優先。

**筆畫種類（哪一筆對哪件物品）只信人工標註。** `scripts/verified-strokes.mjs` 是已核對名單的單一來源，
腳本會用抓回來的資料驗證筆數是否吻合，不吻合就降為待核並在報告裡列出來。
腳本裡的幾何分類器只寫進 `stroke-report.json` 當建議，絕不直接當答案。

## 字義與組詞來自萌典

練習頁右欄的「字義・組詞」卡由 `src/lib/moedict.ts` 取萌典：`/uni/{字}.json` 給注音、詞性、白話釋義與例詞，
`/c/{字}.json` 給英文對譯，`/uni/{詞}.json` 給點開某個組詞時的詞義。只取白話 `def` 與「如：」例詞，
文言引例與整句古語都不顯示，姓氏、人名、地名、譯音那幾條也跳掉。

組詞先掃辭典每一條釋義裡的例詞（辭典自己給的搭配，最準），不夠四個才打 `functions/api/dict/words.ts`
從萌典詞目索引補，並要求每個字都在小學字包裡，免得撈到「進尺」「水厄」這種。索引檔 2.2 MB，
所以由 Pages Function 用 Cache API 存一個月，前端只收幾十位元組。取回來的結果進 IndexedDB，
離線就用舊快取，真的取不到整張卡不顯示。

```bash
npx vite-node scripts/eval-gloss.ts   # 抽驗 10 個字的注音、釋義、組詞、英文
```

## 位置與判定都是幾何，沒有影像辨識

目標槽位（該擺哪裡、轉幾度、多長）由每一筆的 `medians` 中線算出來，不必逐字手排座標。
「拼好了」就是拿學生擺的物件跟目標中線做比對，分三層：

- `kind` 有沒有用對物件種類
- `order` 放置次序是否合筆順
- `placement` 位置、角度、長度是否落在容差內

種類與位置都對、且沒有多放才算過關；筆順分另外顯示，不擋過關。

座標系沿用 makemeahanzi：邊長 1024，左上角是 `(0, 900)`、y 軸向下遞減，
`src/lib/geometry.ts` 一律先轉成 0–1 正規化座標。

## 開發

```bash
npm install
npm run dev
npm run build
```

部署走站台的 `scripts/build.mjs`，輸出到 `dist/巧手拼拼字/`。舊路徑 `/巧手猜猜字/` 與 `/巧手猜猜畫/` 會轉到新網址。
